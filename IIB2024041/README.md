# SQL Injection - Authentication Bypass

## Cyber Security Assignment

### Vulnerability
SQL Injection - Variant 1: Authentication Bypass

### Vulnerable Application

This application demonstrates an intentionally vulnerable login system
for an authorized academic security assignment.

The application is vulnerable to SQL Injection authentication bypass.

### Secure Application

The vulnerability is mitigated using parameterized SQL queries.

### Demonstration

1. Normal login
2. Failed login with incorrect credentials
3. SQL Injection authentication bypass
4. Explanation of vulnerable SQL query
5. Parameterized-query mitigation
6. Same SQL Injection attempt fails after mitigation

### Technologies

- Python
- Flask
- SQLite
